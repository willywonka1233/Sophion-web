### 1.2 Los 6 arquetipos de gancho (esto es el oro)

Cada gancho de esta cuenta cae en uno de estos 6 moldes. Son plantillas rellenables:

1. **Autoridad prestada** → *"Un neurocientífico de Stanford / un neurólogo de Zúrich / los científicos descubrieron que..."*
   Toma prestada credibilidad de una institución. Baja el escepticismo, sube los guardados.

2. **Estudio contraintuitivo** → *"Un estudio afirma que las personas que [rasgo raro] tienen [ventaja sorprendente]."*
   Lo inesperado se comparte. La gente etiqueta a un amigo.

3. **Espejo de identidad** → *"Las personas muy inteligentes / altamente sensibles / que aman su casa tienen [X cualidades]."*
   El lector se reconoce, comenta "soy yo", se lo envía a alguien. **Es el que más engagement genera** (5K–18K likes en esta cuenta).

4. **Bucle abierto (open loop)** → *"...hay una razón más profunda:" / "¿La solución? Sorprendentemente física:" / "lo que encontró fue esto:"*
   Retiene el pago para la siguiente slide. Obliga a deslizar → sube el tiempo de permanencia → el algoritmo lo premia.

5. **Reencuadre contrario ("no X, sino Y")** → *"No eres antisocial. Tienes baja tolerancia a lo falso." / "No es más emotivo. Es más sensible."*
   Valida al lector y le da una identidad mejor. Genera lealtad.

6. **Especificidad numérica** → *"40 años", "30 segundos", "1 de cada 5", "11 cualidades".*
   Los números concretos = credibilidad + insinúan cuántas slides hay (promesa de contenido).

> **Los mejores ganchos combinan 2–3 arquetipos.** Ej. #8 = Autoridad + Especificidad + Promesa. #11 = Identidad + Bucle abierto.

### 1.3 Por qué mecánicamente generan alcance

- **Contenido de identidad → guardados + compartidos + comentarios.** La gente se etiqueta ("Dinamica", "Mente", "soy yo"). Instagram interpreta guardar/compartir como la señal más fuerte y amplía el alcance.
- **Bucles abiertos → deslizamiento completo.** Cuanto más deslizas, más tiempo de permanencia, más lo muestra el algoritmo.
- **Estética de una sola plantilla → reconocimiento de marca + velocidad.** Publican a diario porque el molde visual es fijo: mismo fondo, misma tipografía, mismo layout. El feed se ve intencional.
- **Temas universales** (amor, estrés, inteligencia, introversión) → alcance amplio y frío (no-seguidores).
- **Cero fricción de producción.** Texto sobre fondo simple = se puede producir en 10 minutos.

**Lección para Sophion:** el éxito no está en imágenes bonitas, está en el **gancho + la estructura + la consistencia**. La imagen solo tiene que verse premium y coherente.

## PARTE 3 — Sistema de producción de imágenes (ChatGPT + Pinterest)

Aquí está la parte técnica que pediste. Separa siempre **3 capas**:

```
CAPA 1 — Fondo/atmósfera   → generado con ChatGPT (GPT-Image/DALL·E) o sacado de Pinterest
CAPA 2 — Texto             → SIEMPRE en Canva, NUNCA generado por IA (la IA escribe texto mal)
CAPA 3 — Marca             → logo Sophion + grano + gradiente de color consistente (en Canva)
```

> **Error #1 de principiantes:** pedirle a la IA que ponga el texto. La IA deforma letras. El texto se pone en Canva con tu tipografía fija. La IA solo hace el **fondo/imagen de apoyo**.

### 3.1 Ruta A — Generar fondos con ChatGPT (recomendado para tu marca premium)

Tu marca es minimalista/monocromática, así que las imágenes de IA deben ser **texturas y atmósferas sutiles**, no ilustraciones ruidosas. Pídele a ChatGPT imágenes en formato **1080x1350 (4:5, vertical)** — es el formato que más pantalla ocupa en el feed.

### 3.2 Ruta B — Pinterest (rápido, para mood y fondos listos)

1. Busca términos como: *"dark academia minimal", "grainy texture background", "brutalist minimal poster", "moody film photography", "greek statue dark", "black paper texture"*.
2. Úsalo como **referencia de estilo** para tus prompts, o como fondo directo si es libre de derechos.
3. Precaución legal: no reutilices fotos con marca de agua o de autor identificable para vender. Mejor: usa Pinterest para **definir el mood** y luego genera tu propia versión con IA (así es 100% tuyo y único).

**Flujo recomendado:** Pinterest para encontrar el estilo → describir ese estilo en un prompt de ChatGPT → generar imagen original tuya → texto en Canva. Así consigues identidad **única y sin problemas de derechos**.

## PARTE 4 — Cómo formular prompts con identidad ÚNICA

La identidad visual única no viene de un prompt genial suelto — viene de **repetir el mismo "ADN de prompt" en todas las imágenes**. Ese ADN es un conjunto fijo de modificadores que bloqueas y no cambias. Estructura del prompt:

```
[SUJETO] + [MEDIO/TÉCNICA] + [ILUMINACIÓN] + [PALETA DE COLOR] + [TEXTURA] +
[COMPOSICIÓN/ESPACIO NEGATIVO] + [MOOD] + [FORMATO] + [NEGATIVOS]
```

- **Espacio negativo obligatorio** → necesitas zona vacía para poner el texto encima. Pide siempre *"large empty negative space at top/center for text overlay"*.
- **Formato** → *"vertical 4:5 aspect ratio, 1080x1350"*.
- **Negativos** → *"no text, no words, no letters, no watermark, no logo"*.

### 4.2 El "kit de consistencia" (bloquéalo y no lo cambies)

Para que TODA la cuenta se vea de la misma marca, fija estos 5 elementos y repítelos:

1. **Paleta:** máximo 3 colores (ej. hueso `#EDE9E3`, grafito `#1C1C1C`, un acento). 
2. **Tipografía:** 1 serif elegante para ganchos (ej. una didone/serif) + 1 sans-serif limpia para cuerpo. Siempre las mismas.
3. **Grano/textura:** aplica el mismo overlay de grano en Canva a cada imagen → une todo.
4. **Layout del texto:** misma posición, mismo tamaño, misma alineación en cada slide.
5. **Firma:** logo o "@sophionclub" pequeño en la misma esquina siempre.

> **Truco pro:** genera 20 fondos de golpe con el mismo prompt base (cambiando solo el sujeto), y tendrás munición para 20 posts con identidad idéntica. La consistencia se produce en lote.

## PARTE 7 — Flujo de trabajo semanal (para producir en serie)

1. **Lunes (planificación, 30 min):** elige 3 ganchos del banco (Parte 5.2). Rota los 6 pilares.
2. **Lunes (imágenes en lote, 45 min):** genera los ~27 fondos (3 carruseles × 9 slides, aunque muchas slides internas usan fondo liso) con el prompt base fijo de tu Dirección elegida. Descarga todo.
3. **Martes (montaje en Canva, 1–2 h):** crea UNA plantilla maestra con tu kit de consistencia. Duplica y rellena el texto. Aplica grano + logo iguales.
4. **Miércoles (captions):** escribe los 3 captions con la fórmula de la Parte 2.
5. **Programa:** 3–5 carruseles/semana. La consistencia de publicación importa tanto como la de diseño.
